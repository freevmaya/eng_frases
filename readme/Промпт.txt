*Общая концепция для кодинга*

Придерживайся объектно-ориентированной концепции.
Придерживаться изначальных именований классов, методов, функций, констант, переменных и не переименовывать при модификации.
Если требуется создать отдельный класс и код его больше 100 строк, создавай его в отдельном файле. Файл располагать в соответствующей папке.
Константы должны быть написаны в ВЕРХНЕМ РЕГИСТРЕ
При модификации кода: 
Показывать полностью код нужно если только изменения затрагивают более 10% кода. 
Если изменений меньше, тогда показывай только места где требуется внести изменения.

*Описание*
Это интерактивное приложение для изучения английских фраз и предложений.

Для эффективного запоминания и доведения речевых навыков до автоматизма рекомендуем чередовать последовательность воспроизведения русской и английской версий фраз.
